# 阶段 0 阶段总结

阶段 0 已经形成一个可以继续扩展的最小语言实验器。当前可以执行一个 `.中` 文件，将整数赋值和整数表达式的结果保存到变量环境：

```bash
GOCACHE=/tmp/xu-go-cache go run ./cmd/zhongwen 运行 examples/阶段0/最小赋值.中
```

输出：

```text
环境[名字=1]
```

也可以执行两条赋值：

```bash
GOCACHE=/tmp/xu-go-cache go run ./cmd/zhongwen 运行 examples/阶段0/两条赋值.中
```

输出：

```text
环境[名字=1, 年龄=18]
```

这不是一门已经完成的语言。当前值类型仍然只有整数，表达式能力也只覆盖本阶段定义的四则运算。

当前也可以引用前面已经定义的变量：

```bash
GOCACHE=/tmp/xu-go-cache go run ./cmd/zhongwen 运行 examples/阶段0/变量引用.中
```

输出：

```text
环境[名字=1, 总数=1]
```

整数表达式示例：

```bash
GOCACHE=/tmp/xu-go-cache go run ./cmd/zhongwen 运行 examples/阶段0/整数表达式.中
```

输出：

```text
环境[基数=10, 总数=34]
```

当前四则运算遵守乘除优先、加减次之的规则，括号可以改变计算顺序。除数为零时会返回带位置的中文错误。

这仍然不是一门已经完成的语言。当前没有文字、输出语句、布尔、条件、循环、函数和模块。下一步进入 M2，研究文字字面量和最小输出语句。
