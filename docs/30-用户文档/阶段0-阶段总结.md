# 阶段 0 阶段总结

阶段 0 完成了一个最小可运行样本。当前可以执行一个 `.中` 文件，并将整数赋值保存到变量环境：

```bash
GOCACHE=/tmp/xu-go-cache go run ./cmd/zhongwen 运行 examples/阶段0/最小赋值.中
```

输出：

```text
环境[名字=1]
```

也可以执行两条赋值：

```bash
GOCACHE=/tmp/xu-go-cache go run ./cmd/zhongwen 运行 examples/阶段0/两条赋值.中
```

输出：

```text
环境[名字=1, 年龄=18]
```

这不是一门已经完成的语言。当前只支持整数常量和已定义整数变量的赋值，下一步会研究最小算术表达式。

当前也可以引用前面已经定义的变量：

```bash
GOCACHE=/tmp/xu-go-cache go run ./cmd/zhongwen 运行 examples/阶段0/变量引用.中
```

输出：

```text
环境[名字=1, 总数=1]
```
