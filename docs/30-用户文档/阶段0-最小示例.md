# 阶段 0：最小示例

这是当前语言最小的一条整数赋值示例：

```text
设置 名字 = 1
```

示例文件位于：

```text
examples/阶段0/最小赋值.中
```

当前 CLI 已经可以运行这个文件：

```bash
GOCACHE=/tmp/xu-go-cache go run ./cmd/zhongwen 运行 examples/阶段0/最小赋值.中
```

预期输出：

```text
环境[名字=1]
```

更多语法见 [阶段 0：整数表达式](./阶段0-整数表达式.md)。

也可以运行完整测试：

```bash
GOCACHE=/tmp/xu-go-cache go test ./...
```
