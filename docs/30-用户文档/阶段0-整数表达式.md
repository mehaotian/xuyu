# 阶段 0：整数表达式

当前阶段支持在赋值语句右侧使用整数、已经定义的变量和四则运算。

## 示例

```text
设置 基数 = 10
设置 总数 = (基数 + 2) * 3 - 4 / 2
```

运行：

```bash
GOCACHE=/tmp/xuyu-go-cache go run ./cmd/zhongwen 运行 examples/阶段0/整数表达式.中
```

输出：

```text
环境[基数=10, 总数=34]
```

## 运算规则

- `*` 和 `/` 的优先级高于 `+` 和 `-`；
- 同一层级从左到右计算；
- 括号可以改变默认优先级；
- 变量必须先定义后使用；
- 所有运算结果都是整数，除法采用整数除法；
- 除数为零会报告执行错误和源码位置。

例如：

```text
设置 一 = 10 - 2 - 3
设置 二 = 10 - (2 - 3)
```

结果分别是 `5` 和 `11`。

## 当前限制

- 不支持一元负号，因此 `设置 数字 = -1` 不是合法写法；
- 不支持小数、比较、布尔、文字和字符串拼接；
- 暂不单独检查整数溢出，溢出策略留待后续设计；
- 赋值仍然是当前唯一的语句类型。
