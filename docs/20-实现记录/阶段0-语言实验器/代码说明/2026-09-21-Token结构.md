# Token 结构说明

## 这一步解决什么

Token 是源码进入语法分析前的最小单位。当前先把“类别、原文和源码范围”这三件事固定下来，给后面的 Lexer 一个明确输出目标。

## 当前类别

- `无效`：暂时无法识别的内容；
- `文件结束`：输入已经结束；
- `关键字`：例如 `设置`；
- `标识符`：例如 `名字`；
- `整数`：例如 `123`；
- `等号`：赋值语句中的 `=`。

这里只定义下一步实验需要的类别，没有提前加入全部关键字、文字、括号和运算符。

## 位置规则

`Offset` 使用 UTF-8 字节偏移，`Line` 和 `Column` 从 1 开始。范围的结束位置采用半开区间：内容从 `Start` 开始，到 `End` 之前结束。

这一步还没有计算位置。Lexer 开始后，需要补充中文字符、英文字符和换行的实际计数测试。

## 没有做什么

- 没有从文件或字符串读取源码；
- 没有把源码切成 Token；
- 没有把标识符转换成 SymbolID；
- 没有实现 Token 的语义检查。
