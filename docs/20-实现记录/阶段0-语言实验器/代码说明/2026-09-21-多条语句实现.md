# 多条语句实现说明

## 这一步解决什么

语句边界实验决定暂时使用换行分隔顶层语句。这一步把决定落实到 Lexer、Parser 和 Runner，让一个文件可以顺序执行多条整数赋值。

## 当前示例

```text
设置 名字 = 1
设置 年龄 = 18
```

运行结果：

```text
环境[名字=1, 年龄=18]
```

## 实现规则

- Lexer 将换行保留为 `换行` Token；
- Parser 忽略文件开头、文件结尾和连续空行；
- 两条赋值之间必须至少有一个换行；
- 没有换行的相邻赋值会报错；
- EOF 可以结束最后一条语句；
- Interpreter 按源码顺序写入同一个变量环境。

## 当前没有解决

- 括号内换行；
- 多行文字；
- 注释；
- 缩进和代码块；
- 分号；
- 变量引用和表达式。
