# Lexer 最小实现说明

## 这一步解决什么

Lexer 负责把源码从一段文字切成 Token。当前只实现最小范围，让后续 Parser 有一个稳定的输入格式。

## 当前支持

```text
设置        关键字
名字        中文标识符
player_1    英文和下划线标识符
123         整数
=           等号
空格/换行    跳过
```

关键字只识别完整的 `设置`。例如 `设置值` 会作为一个标识符，不会被拆成 `设置` 和 `值`。

## 位置计算

- `Offset` 是 UTF-8 字节偏移；
- `Line` 和 `Column` 从 1 开始；
- 列号按 Unicode 字符计数，不按终端显示宽度计数；
- 换行后行号加一，列号回到 1；
- Token 范围使用半开区间。

## 错误处理

当前遇到无法识别的字符会立即返回错误，并带上起始位置。Lexer 不会根据相似字符猜测用户意图。

## 没有做什么

- 没有识别文字、布尔、小数、括号和运算符；
- 没有读取文件；
- 没有实现注释；
- 没有实现错误恢复；
- 没有把 Token 交给 Parser。
