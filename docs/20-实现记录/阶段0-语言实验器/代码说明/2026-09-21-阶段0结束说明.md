# 阶段 0 结束说明

阶段 0 留下了一条完整但很窄的执行路径。它的价值不是功能多，而是把每一层的责任固定下来：

```text
文件 -> Lexer -> Parser -> AST -> Interpreter -> 环境
```

后续参与者可以从以下位置开始阅读：

1. `cmd/zhongwen/main.go`：命令参数和用户输出；
2. `internal/runner/runner.go`：各层的连接处；
3. `internal/lexer/lexer.go`：源码如何变成 Token；
4. `internal/parser/parser.go`：Token 如何变成 AST；
5. `internal/ast/ast.go`：程序结构；
6. `internal/interpreter/interpreter.go`：AST 如何影响变量环境。

当前最重要的技术问题不是增加更多节点，而是决定多条语句如何分隔。这个决定会影响 Lexer、Parser、错误位置和后续格式化器，因此单独作为下一步实验。
