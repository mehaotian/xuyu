# 阶段 0 链路总览

## 当前链路

```text
最小赋值.中
    ↓（当前由测试提供源码字符串）
Lexer
    ↓
Token
    ↓
Parser
    ↓
AST
    ↓
Interpreter
    ↓
环境[名字=1]
```

## 各层职责

- `Lexer` 只负责切分文字，不判断语句是否完整；
- `Token` 保存类别、原文和源码范围；
- `Parser` 只负责把 Token 组成 AST，并报告语法错误；
- `AST` 表达程序结构，不负责执行；
- `Interpreter` 执行 AST，并维护变量环境。

## 当前缺口

源码文件还没有经过 CLI 进入这条链路。现在的集成测试在测试代码中调用 Lexer、Parser 和 Interpreter，因此 0.7 复盘后的下一步是增加最小文件运行命令，而不是增加新的语言语法。
