# 项目骨架说明

## 阅读顺序

1. `go.mod`：项目模块名和 Go 版本。
2. `cmd/zhongwen/main.go`：当前唯一的程序入口。
3. `cmd/zhongwen/main_test.go`：入口行为的三个最小测试。
4. `examples/阶段0/`：后续保存语言源码示例。
5. `tests/阶段0/`：阶段测试说明。

## 当前实现

命令入口只识别帮助和版本两个命令。没有参数时显示帮助；收到未知命令时给出提示。

这里还没有 Token、Lexer、Parser、AST 或解释器。故意保留这个边界，先确认项目可以被构建、运行和测试。

## 目录约定

编译器实现从 `internal/` 开始，命令入口放在 `cmd/`。Go 包目录使用 ASCII，避免目录名成为非法导入路径；最终生成的命令和用户界面仍然可以使用中文。早期目录可以调整，稳定的语言 API 以后再单独设计。
