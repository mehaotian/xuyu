# 阶段 0 复盘

**日期：** 2026-09-21
**范围：** 项目骨架、Token、Lexer、AST、Parser、整数赋值解释器

## 已经成立的部分

1. Go 项目可以在本地构建和测试；
2. 中文命令输出和中文源码字符串可以正常处理；
3. Lexer 能识别最小词法单元，并提供源码位置；
4. Parser 能把一条赋值语句变成 AST；
5. Interpreter 能把 AST 执行到变量环境；
6. 每一层都有单独的测试和中文说明。

## 当前没有成立的部分

1. CLI 还不能读取 `.中` 文件；
2. 用户无法通过一条命令看到完整执行结果；
3. 语言还不能处理变量引用、表达式、输出、条件和循环；
4. `example.com/zhongwen` 仍是临时模块名；
5. 关键字、错误格式和源码扩展名还没有最终冻结。

## 本轮复盘结论

当前前端最小链路已经足够进入“命令行闭环”实验，但还不能宣称阶段 0 完成。继续增加语言语法之前，应先让一个 `.中` 文件能够通过 CLI 进入现有链路并显示结果。

## 保留的设计决定

- Go 实现目录使用 ASCII，避免非法包导入路径；
- 用户可见的命令和诊断继续使用中文；
- Lexer 对关键字采用完整匹配，不根据相似文字猜测；
- Parser 和 Interpreter 保持独立，不在解释器中重新解析源码；
- 本阶段不接入第三方库。

## 下一步建议

增加 0.8：CLI 最小运行闭环。输入一个 `.中` 文件，依次调用 Lexer、Parser 和 Interpreter，最后打印变量环境。不增加新的语法特性。
