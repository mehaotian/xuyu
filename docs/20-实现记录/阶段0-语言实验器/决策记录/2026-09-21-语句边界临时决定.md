# 语句边界临时决定

**日期：** 2026-09-21
**决定：** 下一步实验实现换行 Token，使用换行分隔顶层语句

## 原因

- 当前语言需要先支持多条简单赋值；
- 换行最容易对应源码位置和错误信息；
- 不要求用户额外输入分号；
- 缩进应该留给后续代码块，而不是承担顶层语句结束；
- 暂时不加入新的可见标点。

## 影响

- Token 新增 `换行` 类别；
- Parser 需要忽略文件开头、文件结尾和连续空行；
- 多条赋值可以在一个文件中顺序执行；
- 后续加入括号、文字和注释时，必须重新检查换行规则。

## 撤回条件

如果真实示例显示换行无法稳定区分多行表达式，或者错误恢复明显变差，应重新比较显式分隔符和缩进方案，不要为了保持当前决定而强行扩展规则。
