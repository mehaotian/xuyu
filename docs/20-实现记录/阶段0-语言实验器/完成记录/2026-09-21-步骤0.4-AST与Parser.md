# 步骤 0.4：AST 与单条赋值语句 Parser

**日期：** 2026-09-21
**状态：** 已完成

## 做了什么

- 创建 `internal/ast`，定义程序、语句和表达式的最小边界；
- 创建 `internal/parser`，解析一条整数赋值语句；
- 添加带源码范围的语法错误；
- 添加 AST 结构、成功解析、缺少值和多余 Token 测试；
- 打通 `Lexer -> Token -> Parser -> AST` 的最小链路。

## 没有做什么

- 没有执行 AST；
- 没有变量环境；
- 没有解析条件、循环、函数或复杂表达式；
- 没有把 Parser 接入 CLI。

## 验证

运行 `GOCACHE=/tmp/xu-go-cache go test ./...`，所有测试通过。

## 遗留问题

- AST 当前只支持整数赋值，表达式结构还没有展开；
- Parser 需要更好的错误恢复，但当前阶段先保持严格失败；
- `设置` 关键字和变量名的语义还没有进入解释器。
