# 步骤 0.6：解释器执行整数赋值

**日期：** 2026-09-21
**状态：** 已完成

- 创建 `internal/interpreter`；
- 添加整数变量环境；
- 让解释器执行 AST 中的赋值语句；
- 提供变量写入、读取和稳定调试输出；
- 添加源码到变量环境的集成测试。

- 没有接入 CLI；
- 没有设计完整运行时或垃圾回收。

## 验证

运行 `GOCACHE=/tmp/xu-go-cache go test ./...`，所有测试通过。
