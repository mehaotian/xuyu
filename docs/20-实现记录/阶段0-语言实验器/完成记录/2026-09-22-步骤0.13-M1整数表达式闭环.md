# 步骤 0.13：M1 整数表达式闭环

**日期：** 2026-09-22
**状态：** 已完成

## 做了什么

- Lexer 增加加号、减号、乘号、除号和括号 Token；
- AST 增加二元整数表达式；
- Parser 按加减、乘除、括号和基本值分层处理优先级；
- Interpreter 执行整数四则运算；
- 除数为零时返回带源码位置的中文错误；
- 增加词法、语法、解释器、文件运行和 CLI 级别的表达式测试；
- 增加整数表达式示例和用户说明。

## 没有做什么

- 没有实现一元负号；
- 没有制定整数溢出策略；
- 没有实现小数、比较、布尔、文字和字符串拼接；
- 没有改变 CLI 的输出形式，当前仍显示变量环境。

## 验证

```bash
GOCACHE=/tmp/xuyu-go-cache go test ./...
GOCACHE=/tmp/xuyu-go-cache go vet ./...
GOCACHE=/tmp/xuyu-go-cache go run ./cmd/zhongwen 运行 examples/阶段0/整数表达式.中
```

预期输出：

```text
环境[基数=10, 总数=34]
```

## 实现边界

括号只参与解析分组，不单独生成运行时值。整数除法沿用 Go 的整数除法行为；除零在解释器中显式拦截，整数溢出暂不处理。
