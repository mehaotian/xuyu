# 步骤 0.11：多条整数赋值

**日期：** 2026-09-21
**状态：** 已完成

## 做了什么

- 新增 `换行` Token；
- Lexer 保留换行，仍然跳过空格和横向空白；
- Parser 忽略开头、结尾和连续空行；
- Parser 支持同一文件中的多条整数赋值；
- Runner 和 CLI 可以运行多条赋值文件；
- 新增两条赋值示例和对应测试。

## 没有做什么

- 没有实现变量引用；
- 没有实现算术表达式；
- 没有实现分号、缩进 Token、括号和注释；
- 没有实现条件、循环或函数。

## 验证

运行：

```bash
GOCACHE=/tmp/xu-go-cache go test ./...
GOCACHE=/tmp/xu-go-cache go run ./cmd/zhongwen 运行 examples/阶段0/两条赋值.中
```

实际输出：

```text
环境[名字=1, 年龄=18]
```

## 遗留问题

- 换行规则还没有和括号、文字、注释结合验证；
- 变量环境目前只能保存整数常量；
- AST 的表达式接口还没有真正出现第二种表达式。
