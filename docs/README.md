# 现代中文编程语言实验项目文档

## 文档说明

本目录是对项目立项材料的整理、评审和工程化补充。原始材料的定位是产品设计草稿（PDR v0.1）；本目录中的内容是基于原始设想形成的“整理评审版”。项目目前是个人开发者发起的实验项目，欢迎爱好者共同参与，不以成为主流语言或击败 Python、Go、Rust 为目标。

文档明确区分：

- 已确认的产品目标
- 建议采用的工程方案
- 仍需实验验证的候选设计
- 当前不应承诺的长期目标

文档中的“建议”不是已经完成的实现，开发前应通过语言实验、原型和用户测试逐项确认。

## 当前一句话定义

> 一个以现代中文为原生源码体验的编程语言实验项目，用来探索严格语法、中文开发工具链和社区协作的结合方式。

## 当前最高优先级结论

1. 先做一个能运行、能阅读、能继续修改的最小实验器，不先承诺完整生态。
2. 采用解释器优先、IR 复用、原生后端后置的路线，逐步理解每一层的作用。
3. 中文输入辅助放在 IDE，不放进编译器推测；编译器必须确定、可复现、可审计。
4. v0.1 只冻结最小语法和语义，泛型、并发、宏、调试器、跨平台发布等进入后续决策门。
5. 项目的价值在于探索、学习、共享和积累，不以市场占有率或击败成熟语言作为验收标准。

## 文档维护规则

- 语言规范变更必须同时更新示例、AST/IR 说明和测试用例。
- 所有“最终支持”都必须绑定目标平台、版本和验收标准。
- 候选语法不得直接写入稳定规范；先标注为“实验性”，并记录实验结果。
- 引入外部依赖、包仓库或运行时能力时，必须记录许可证、安全和离线构建影响。
- 每次开发只完成一个可阅读的小步骤；完成后记录并停下，不在同一轮隐式扩展范围。
