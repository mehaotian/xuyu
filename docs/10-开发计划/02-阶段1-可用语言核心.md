# 阶段 1：可用语言核心

本阶段只有在阶段 0 复盘完成后才开始。目标是让语言可以承担几个小型真实任务，而不是补齐所有现代语言特性。

## 计划范围

- 文字、布尔、小数、列表和映射；
- 函数、作用域、返回值和基础错误；
- 条件、次数循环、显式集合遍历；
- 基础对象模型；
- 中文诊断和格式化规则；
- 文件、路径、JSON、时间等少量标准库。

## 明确暂缓

泛型、宏、继承、并发、异步、JIT、插件系统、公共包仓库、Native 后端和完整调试器。

## 进入条件

- 阶段 0 有可回看的实现记录；
- 关键字和循环形式经过真实代码实验；
- 基础错误模型已经写成规则；
- 参与者能够在不依赖作者口头解释的情况下运行项目。
