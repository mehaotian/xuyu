# 当前阶段整合计划

**制定日期：** 2026-09-22
**基础版本：** 已完成源码文件、Lexer、Parser、AST、Interpreter、CLI、变量引用和 M1 表达式闭环

**当前进度：** M1 已完成，下一步进入 M2。

## 1. 评估结论

当前代码边界已经稳定到可以合并相关功能一起推进。继续把每个运算符拆成单独步骤，会反复修改 Token、AST、Parser 和 Interpreter，反而增加阅读和维护成本。

下一阶段改为“一个完整能力闭环一个里程碑”。每个里程碑包含语法设计、实现、错误处理、测试、示例和文档，完成后暂停评审。

## 2. 里程碑 M1：整数表达式闭环

### 目标

支持：

```text
设置 基数 = 10
设置 总数 = (基数 + 2) * 3 - 4 / 2
```

### 一起完成的内容

- `+`、`-`、`*`、`/`、`(`、`)` Token；
- 二元表达式 AST；
- 整数、变量和括号表达式；
- 乘除高于加减的优先级；
- Interpreter 整数运算；
- 除零错误和对应源码位置；
- 合法、非法、优先级和 CLI 集成测试；
- 可运行示例和用户说明。

### 明确不做

一元负号、整数溢出策略、小数、比较、布尔、字符串拼接和隐式类型转换。

### 完成标准

- 表达式优先级测试通过；
- 变量能够参与运算；
- 除零返回中文错误；
- CLI 能运行一个包含表达式的 `.中` 文件；
- 文档说明运算规则和当前限制。

## 3. 里程碑 M2：用户输出闭环

### 目标

支持：

```text
设置 名字 = 「世界」
输出 名字
```

### 一起完成的内容

- 中文文字字面量 `「」`；
- `输出` 关键字和语句 AST；
- 文字值进入运行环境；
- Interpreter 输出缓冲区；
- CLI 打印程序输出，而不是只打印调试环境；
- 未闭合文字、错误值类型和输出顺序测试。

### 明确不做

字符串插值、转义全集、文件输出、格式化模板和标准输入。

## 4. 里程碑 M3：条件与代码块闭环

### 目标

支持最小条件分支：

```text
如 总数 > 10：
    输出 「较大」
否则：
    输出 「较小」
```

### 一起完成的内容

- 布尔值和比较运算；
- `如`、`否则` 和中文冒号；
- 缩进、反缩进 Token；
- 条件 AST 和解释执行；
- 缩进错误、条件类型错误和嵌套测试。

### 明确不做

循环、函数、对象、异常、并发和模式匹配。

## 5. 当前提交边界

每次 Git 提交只包含已经完成并验证的能力，以及对应的测试、示例和文档。未完成的里程碑不能在提交说明或首页中写成已实现能力；当前 M2 和 M3 仍是后续工作。
