# 开发计划

## 这份计划怎么用

本项目采用“小步、可读、可停”的开发方式。每个步骤只解决一个问题，完成后留下代码、测试、说明和实现记录，然后暂停等待阅读和确认。

不要把整阶段当成一次任务。阶段只是方向，当前步骤才是实际工作范围。

## 每一步的固定产物

每次开发至少留下以下内容：

1. 一段可以运行的代码，或一个明确可验证的结构；
2. 对应测试；
3. 一份简短的中文说明，解释新增内容和没有做的内容；
4. 一份实现记录，记录遇到的问题和暂时决定；
5. 下一步建议，但不自动执行下一步。

## 每一步的停止条件

满足以下条件就停止本轮：

- 当前目标已完成；
- 测试或验证已执行；
- 代码和注释可以独立阅读；
- 文档已说明当前实现边界；
- 没有顺手加入下一阶段功能。

## 当前不做的事

- 不一次实现完整编译器；
- 不在 Lexer 之前引入 LLVM、WASM、LSP 或包管理器；
- 不为了“看起来完整”预先写大量空模块；
- 不在没有实验代码的情况下冻结全部语法；
- 不把未经验证的代码、文档或建议写成已经完成的结论。
