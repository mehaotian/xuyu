# XuYu

XuYu 是一个现代中文编程语言实验项目，用来探索中文源码、确定性语法、编译器前端和开发工具链如何形成一套清晰、可维护的开发体验。

项目由个人发起，面向编程语言和编译器爱好者共同建设。它不以替代 Python、Go、Rust 等成熟语言为目标，也不把成为主流语言作为成功条件。当前重点是把每一层实现做小、做实，并留下可以阅读、验证和继续扩展的代码与文档。

## 项目目标

- 让中文标识符和中文关键字成为源码的一等组成部分；
- 使用严格、确定、可测试的语法，不依赖模糊猜测；
- 用中文提供错误信息、示例和开发文档；
- 从 Lexer、Parser、AST 和解释器开始，逐步建立完整工具链；
- 保持源码结构清楚，让新的参与者能够快速找到入口并完成小改动。

## 当前状态

项目处于语言实验器阶段，已经打通：

```text
.中 源码
  -> Lexer
  -> Token
  -> Parser
  -> AST
  -> Interpreter
  -> 变量环境
```

当前支持：

- 中文和 ASCII 标识符；
- 整数常量；
- 多条赋值语句；
- 已定义整数变量的引用；
- 整数四则运算、括号和运算优先级；
- 中文词法、语法和执行错误；
- 通过 CLI 运行单个 `.中` 文件。

当前不支持文字、布尔、输出语句、条件、循环、函数、模块和原生编译。

## 快速体验

环境要求：Go 1.22 或更高版本。

运行最小示例：

```bash
go run ./cmd/zhongwen 运行 examples/阶段0/最小赋值.中
```

预期输出：

```text
环境[名字=1]
```

运行变量引用示例：

```bash
go run ./cmd/zhongwen 运行 examples/阶段0/变量引用.中
```

预期输出：

```text
环境[名字=1, 总数=1]
```

运行整数表达式示例：

```bash
go run ./cmd/zhongwen 运行 examples/阶段0/整数表达式.中
```

预期输出：

```text
环境[基数=10, 总数=34]
```

运行测试：

```bash
go test ./...
```

如果本地 Go 缓存目录不可写，可以临时指定缓存位置：

```bash
GOCACHE=/tmp/xuyu-go-cache go test ./...
```

## 源码入口

| 目录 | 作用 |
| --- | --- |
| `cmd/zhongwen/` | CLI 参数和用户可见输出 |
| `internal/source/` | 源码位置和范围 |
| `internal/token/` | Token 类型 |
| `internal/lexer/` | 词法分析 |
| `internal/parser/` | 语法分析 |
| `internal/ast/` | 抽象语法树 |
| `internal/interpreter/` | 解释执行和变量环境 |
| `internal/runner/` | 文件读取和执行链路 |
| `examples/` | 可运行的中文源码示例 |
| `docs/` | 规范、计划、实现记录和用户文档 |

建议从 `internal/runner/runner.go` 查看完整调用链，再分别阅读 Lexer、Parser、AST 和 Interpreter。

## 当前开发计划

下一轮继续按完整能力闭环推进：

1. **用户输出闭环**：文字字面量、`输出` 语句和可测试的输出结果；
2. **条件与代码块闭环**：布尔、比较、`如/否则` 和缩进块。

每个闭环完成后暂停评审，不跨阶段加入函数、对象、包管理、LLVM 或 IDE。

详细计划见 [当前阶段整合计划](./docs/10-开发计划/05-当前阶段整合计划.md)。

## 参与项目

开始修改前，请先阅读 [CONTRIBUTING.md](./CONTRIBUTING.md) 和当前阶段计划。一次改动尽量只完成一个闭环中的明确任务，并同时更新测试和实现记录。

项目尚处于实验阶段，语法和内部结构可能调整。对外提交应说明改动目的、验证方式和未解决的问题。
